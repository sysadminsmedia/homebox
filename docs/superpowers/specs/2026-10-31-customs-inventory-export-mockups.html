Customs inventory list: flow

Mockups for the flow in 2026-10-31-customs-inventory-export-design.md. The UI uses the English copy from the spec. The sheet labels are German/English. All names, prices and addresses are made up. Steps 2 and 3 are one dialog: options on the left, the live check on the right.

Blue mono text shows the formula stored in each cell. HomeBox also stores the computed value, so the file shows correct numbers before any recalculation. Column H is the purchase price per piece from HomeBox; column I multiplies it by the quantity (row 9: 4 × 89.50 = 358.00). Quantities and prices are real numbers, dates are real Excel dates, and the currency code is in the column titles. One sheet only; no styling beyond bold rows and column widths.
